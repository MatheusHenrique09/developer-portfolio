## 🛠️ Tecnologias Utilizadas

Este projeto foi construído utilizando as tecnologias fundamentais da web (sem frameworks) para garantir máxima performance e simplicidade:

* **HTML5:** Estruturação semântica do conteúdo.
* **CSS3:** Estilização responsiva e moderna.
* **JavaScript (Vanilla):** Manipulação dinâmica do DOM para renderização das seções e componentes.
* **GitHub Pages:** Hospedagem direta e automatizada a partir do repositório.

## ⚙️ Arquitetura & Estrutura de Arquivos

O portfólio adota uma abordagem modular e escalável. Os dados dos projetos não estão fixos no HTML; eles são lidos dinamicamente de um arquivo JSON mantido na pasta do script.

1. Os dados de cada projeto são gerenciados no arquivo `assets/js/projetos.json`.
2. O arquivo `assets/js/script.js` consome esse JSON e renderiza os cards de projetos na seção correspondente do `index.html`.

Essa estrutura facilita a inclusão de novos projetos no futuro sem a necessidade de alterar a marcação do HTML diretamente.
